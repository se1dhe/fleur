# FLEUR · Presentation

Premium product presentation for **FLEUR**, a Telegram Mini App for a flower-delivery shop in Dnipro, Ukraine.

- **Open the demo bot:** https://t.me/flowersdemo1_bot
- **Live presentation mirror:** https://flowerly-dnipro-tma.vercel.app/fleur/
- **Telegram Mini App source:** https://github.com/se1dhe/fluer-telegram-shop

## Presentation languages

The presentation supports Ukrainian, Russian, and English. Use the language switcher in the header or add `?lang=uk`, `?lang=ru`, or `?lang=en` to the page URL for portfolio screenshots. The Telegram Mini App source and its existing multilingual behavior are unchanged.

## GitHub Pages

The site's entry point is `index.html` in this repository's root; no build tools or npm install are needed.

**One-time GitHub setting (requires repository owner/admin):**

1. Open [Settings → Pages](https://github.com/se1dhe/fleur/settings/pages).
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose **Branch: main**, **Folder: / (root)**, then **Save**.
4. After GitHub finishes deployment, visit **https://se1dhe.github.io/fleur/**.

This repository is under `se1dhe` and named `fleur`, so `/fleur/` is the correct project Pages path. Creating an index.html does not enable GitHub Pages on its own; GitHub must show a successful Pages deployment before sharing the public URL.

## Media and demo safety

The presentation includes externally hosted bouquet catalog images from the FLEUR Mini App deployment; they are real-bouquet-based studio visualizations, not guaranteed representations of every delivered arrangement. Payment options featured in the presentation are simulated workflows — no real card processing, banking, or delivery is enabled.

To update: edit `index.html`; GitHub Pages will rebuild the site after future pushes once Pages is enabled.
